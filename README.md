# Clasificador de Perros y Gatos con Teachable Machine

Este proyecto utiliza TensorFlow.js y Teachable Machine para clasificar imágenes entre perros y gatos en tiempo real desde el navegador.

## Estructura del proyecto
- `index.html`: Interfaz web para subir la imagen y ver el resultado.
- `model/`: Contiene los pesos y metadatos del modelo entrenado.

## Requisitos para probarlo localmente
Debido a las políticas de CORS del navegador, debes ejecutar un servidor web local (por ejemplo, con Live Server en VS Code o `npx http-server`).
